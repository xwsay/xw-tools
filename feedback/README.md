# 💬 xw-tools · 网页极简悬浮留言与赞赏挂件

一个基于 **Cloudflare Workers** + **Telegram Bot** 的无服务器（Serverless）轻量级网页悬浮挂件，支持**在线留言**（带图片上传）与**赞赏支持**（二维码/加密货币）双功能。

---

## ✨ 项目特点

* 🎨 **极简设计**：还原原生 iOS / macOS 设计语言，无冗余动画，视觉体验干净。
* ✉️ **即时推送**：用户留言及截图通过 Telegram Bot 实时推送到你的 TG 群组/频道。
* ☕ **双 Tab 赞赏**：支持展示微信/支付宝收款二维码及 USDT (TRC20) 链上打赏地址。
* ⚡ **零成本运行**：完全依赖 GitHub 静态托管与 Cloudflare Workers 免费额度，无需购买服务器。
* 🛠️ **数据与代码彻底分离**：所有配置（主题色、文案、收款码、链接）均集中在代码顶部的专属配置区，无需改动底层逻辑。
